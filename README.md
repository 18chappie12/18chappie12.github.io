# Bhanu Teja Portfolio

A dependency-free, responsive personal portfolio site.

## Preview locally

Open `index.html` in a browser, or serve this folder with any local static-file server.

## Editing

- Update copy and the project-dialog details in `index.html` and `script.js`.
- Replace `Bhanu-Teja-Resume-Placeholder.txt` with the completed résumé PDF and update the download link in `index.html`.
- Add a direct email address in the contact section when it is ready.

No external services, tracking, or paid APIs are used.
